AFS POS Integration

Take an AFS payment-terminal card payment directly from a posted customer invoice, record the full terminal response against that invoice, register and reconcile the payment, and reverse it with Void while the batch is still open.

Highlights

  • Multiple terminals (afs.terminal), each with its own MID/TID/journal — secrets stay in System Parameters, never on the record.
  • Every API attempt is recorded on afs.transaction as an append-only audit trail, not just the final outcome.
  • Full terminal response (auth code, RRN, STAN, batch, masked PAN, scheme, EMV data) stored on the invoice itself.
  • Void-based full-amount reversal, with pre-flight checks for amount match and open-batch status.
  • A dropped connection during Sale is never retried automatically — recovery is a conservative Enquiry-based heuristic, otherwise the transaction is flagged unknown for manual resolution.

Requirements

  • Odoo 18 Enterprise, Accounting/Invoicing installed.
  • Python package requests.
  • An AFS ECR merchant account and terminal credentials (MID/TID/Tenant/MerchantSecureKey).
